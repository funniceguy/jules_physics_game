# One-Day Dev Plan: Antigravity Prototype

1. **Project Skeleton**: Setup `index.html`, `src` folders, and `matter-js` via CDN/local.
2. **Physics Setup**: Initialize `Matter.Engine`, `Render`, `Runner`.
3. **Game Loop**: Create main entry point and loop structure.
4. **Environment**: Add static ground, walls, and platforms.
5. **Player**: Add a physics body for the player.
6. **Gravity Control**: Implement gravity inversion mechanic.
7. **Controls**: Key listeners for movement and gravity toggle.
8. **Win Condition**: Add a goal zone and collision detection.
9. **UI**: Simple "Press Space to Start" and "You Win!" overlay.
10. **Integration**: Combine all modules into a playable state.
